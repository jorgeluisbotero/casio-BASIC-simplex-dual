# casio-BASIC-simplex-dual
Casio BASIC Simplex and Dual Linear Programming

This is a Casio BASIC implementation of the Simplex algorithm for linear programming optimization, intended for students' use and small size problems.
It is coded in Casio BASIC language, compatible with most of the "modern" casio programmable calculators.

It has been tested and run successfully on a Casio fx 9860 G SD, released in the year 2005; presumably all similar and further programmable Casio calculators models should be able to run this script. It has also been tested successfully on a more recent Casio fx-CG50 (released in 2017).

Why CasioBASIC instead of Python?? -> Because the Python implementation on recent Casio calculators lack the libraries necessary to manipulate matrices and other mathematical objects, while they are fully supported on the older CasioBASIC language.
